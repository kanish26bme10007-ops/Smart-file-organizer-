## Smart file organizer
## Project overview 
    Smart File Organizer is a Python-based application that
    automatically organizes files into categories such as
    Documents, Images, Videos, Audio, and Others. 
    It also provides report generation and undo functionality. 

## Features
    1.File Organization
    2.Report Generation
    3.Undo Operation

## Technology Used
    1.Python 3
    2.os Module
    3.shutil Module
    
## Installation & Run 
    1.Install Python 3.
    2.Download the project files.
    3.Open terminal in the project folder.
    4.Run:python smart_file_organizer.py
    
## Testing instructions 
    1.Create a folder containing different file types.
    2.Run the program.
    3.Enter the folder path.
    4.Select "Organize Files".
    5.Verify files are moved into category folders.
    6.Generate a report.
    7.Test the Undo Operation.
