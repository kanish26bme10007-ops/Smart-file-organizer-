
## Smart file organizer
##  Problem Statement
    Managing files stored in a single folder can be difficult and
    time-consuming. Documents, images, videos, and other files
    often become mixed together, making it hard to locate specific
    files. A system is needed to automatically organize files into
    appropriate categories and improve file management.
## Scope of the Project
    This project organizes files within a user-selected folder by
    categorizing them based on their file extensions. The system
    automatically creates category folders and moves files
    accordingly. It also provides report generation and undo 
    functionality to improve usability and file management.
## Target Users
    - Students
    - Teachers
    - Office Employees
    - Personal Computer Users
## High level features
    - User-Friendly Graphical User Interface (GUI)
    - Folder Selection and Management
    - Automatic File Sorting and Organization
    - Category-Based Folder Creation
    - Organization Report Generation
    - Undo Previous Organization Action
